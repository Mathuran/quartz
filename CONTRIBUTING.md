# Contributing to Quartz

Thanks for your interest in contributing to Quartz!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/quartz.git`
3. Install dependencies: `npm install`
4. Build the extension: `npm run build`

## Development

```bash
# Build once
npm run build

# Watch mode (rebuilds on changes)
npm run build:watch

# Run tests
npm test

# Lint
npm run lint
```

## Testing in VS Code

1. Open the project in VS Code
2. Press `F5` to launch the Extension Development Host
3. Open any `.md` file and select "Open With..." → "Quartz Markdown Editor"

## Pull Requests

1. Create a branch for your feature: `git checkout -b my-feature`
2. Make your changes
3. Run tests: `npm test`
4. Commit with a clear message
5. Push and open a pull request

## Reporting Issues

Please include:
- VS Code version
- Steps to reproduce
- Expected vs actual behavior
- Sample markdown file if relevant
