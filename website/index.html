Quartz

What it is

A block editor for your .md files

Quartz replaces the VS Code markdown preview with a Notion-style editor. Slash commands, drag-and-drop, tables, callouts — writing to standard markdown.

Try the editor Install for VS Code

What's inside

  • Slash commands for every block type
  • Syntax highlighting for 50+ languages
  • Obsidian-compatible callouts
  • Tables with inline editing
  • YAML frontmatter as editable banner
  • Round-trip markdown fidelity
  • Dark & light themes
