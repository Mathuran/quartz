## 1. Text Formatting

It’s easy to make your point with standard styles:

* **Bold text** for emphasis.
* *Italic text* for a subtle touch.
* ***Bold and Italic*** for when you're feeling dramatic.
* ~~Strikethrough~~ for things that are no longer true.
* <u>Underlining</u> (Note: This uses HTML `<u>` tags as standard Markdown doesn't have a native underline).

## 4. Code Blocks and Syntax Highlighting

### Inline Code

To display a variable, use `backticks` like this: `const greeting = "Hello World";`.

### Block Code

You can specify the language for syntax highlighting:

```javascript
function welcome() {
  console.log("Hello, Gemini!");
}

welcome();

```
